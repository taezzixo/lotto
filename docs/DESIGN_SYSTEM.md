# 로또 데이터 실험실 디자인 시스템 규칙

디자인 방향: **「인쇄소의 당첨 장부」**. hallmark 스킬의 **Vellum** 테마(옛 인쇄소: 양피지 바탕, 엄버 잉크, 가는 실선, 안료 한 가지)를 바탕으로 2026-11-19 사용자 요청("고풍스럽게")에 맞춰 바꿨습니다. 이전 방향 「용지와 공」(분홍 마킹 용지)은 이 문서로 대체되었습니다.

- 장부: 모든 면은 납작하게 인쇄된 종이입니다. 모서리 2px, 그림자 없음, 깊이는 가는 실선(1px)으로만 표현합니다. 이중선·섬유 결 장식은 2026-11-19 글꼴 정리(A안) 때 걷어냈습니다.
- 마킹 용지 격자(한 줄 7칸)는 그대로 둡니다. 칸마다 번호, 펜 마킹 진하기(빈도), **출현 횟수 숫자**가 함께 찍힙니다.
- 공식 공 색(1~10 노랑, 11~20 파랑, 21~30 빨강, 31~40 회색, 41~45 초록)은 번호 표시에만 쓰고, 광택 없이 평판 인쇄처럼 칠합니다.
- 움직임은 거의 없습니다(Vellum: Still). 누름·호버 반응만 160ms.

사용한 Claude 스킬(저장소 `.claude/skills/`, 위스키 도감과 같은 5종): frontend-design, ui-ux-pro-max(디자인 시스템 검색: 버건디·금박 계열 권장), hallmark(Vellum 테마·sloplint), emil-design-eng, web-design-guidelines.

**글꼴** — Pretendard 한 가족 (2026-11-19 사용자 결정 A안)

- npm `pretendard@1.3.9`의 가변 글꼴 동적 서브셋을 `src/main.tsx`에서 불러와 앱과 함께 배포(외부 글꼴 서버 없음). 회차 페이지는 jsDelivr의 같은 버전.
- 토큰은 `--font-body` 하나. 한글·영문·숫자가 같은 설계라 장평·기준선이 어긋나지 않습니다.
- 위계는 굵기와 크기로만: 화면 제목 800·`--step-3`·자간 -0.03em, 낱장 제목 700, 큰 숫자(당첨금·카운트다운·운 지수) 800·자간 -0.02em, 본문 400~500. 표·공 숫자는 고정폭(tabular).
- 금지: 두 번째 글꼴 추가, 장식 글꼴(블랙레터·붓글씨), 300 이하 가는 굵기.

공통 패턴
- **낱장** `.sheet`: 1px 실선 둘레 + 위쪽 1px 잉크 선, 머리 아래 실선. 그림자 없음.
- **잉크 선**(`--line-strong` 1px): 상단 머리글 아래, 하단 탭 바 위, 표 머리 아래, 홈 띠 위, 결과 시트 위, 푸터 위.
- **버튼**: `.btn`(안료) / `.btn.ghost`(1px 잉크 테두리). 고르기 `.seg`는 네모 칸을 이어 붙이고 선택 칸만 안료.
- **하단 탭 바**: 화면 폭 전체의 인쇄 띠(넓은 화면은 가운데 560px). 가운데 QR 채점은 네모난 안료 도장.

## 3. 프레임워크·도구

- React 18 + TypeScript + Vite 5, 런타임 의존성 `react` `react-dom` `jsqr`. 스타일은 `src/styles.css` 한 파일.
- 화면 확인: Playwright 스크린샷(390px 라이트·다크, 1280·1480px).
- **디자인 검사**: `node .claude/skills/hallmark/scripts/sloplint.mjs src --genre editorial --scope app` → **FAIL 0** 유지. 면제는 `styles.css` 맨 위 스탬프 아래에 사유와 함께(현재 28b 카메라 미리보기 하나).
- 차트 색 바꿀 때: dataviz 검증 스크립트로 라이트(`#f9f3e8`)·다크(`#531a1e`) 표면 기준 통과 확인.

## 4. 에셋

- 이미지는 PWA 아이콘(`public/icons/*.png`, 군청 인장)과 `favicon.svg`뿐. 회차 페이지(`scripts/prerender.mjs`)도 같은 색·글꼴.
- 이모지를 아이콘으로 쓰지 않습니다. 동행복권 로고·상표는 쓰지 않습니다.

## 5. 쓰지 않는 것

광택·그라데이션 공, 둥근 알약 버튼, 카드 그림자, 두 번째 안료, 양피지 위 옥스블러드 안료(옥스블러드는 다크 바탕만), 찢긴 종이·얼룩·불탄 자국 같은 장식, 대문자 라벨, "A · B" 메타 문자열, 공 색을 장식에 쓰기, 두 번째 글꼴, 설명용 부제 남발(화면이 스스로 설명되게).

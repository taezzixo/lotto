- 화면 (하단 탭 5개, 모바일 우선)
  - **홈**: 최신 회차 공 7개(떨어지는 등장 한 번), 1등 인원·1인당 당첨금·세후 실수령액·자동/수동, 다음 추첨 카운트다운(판매 마감 → 추첨), 캘린더 알림(.ics), 이번 주 내 복권 자동 채점, 최근 5회
  - **통계**: 구간(전체/100/50/15회)·보너스 포함 토글, 마킹 용지 격자 히트맵 + 번호 상세(출현·순위·쉰 회차), 많이·적게·오래 쉰 번호, 번호대 비중 vs 기대, 1등 데이터(최다 1,128회 63명, 최고 1인당 19회 407억, 이월 14회, 연도별 회차당 1등, 생일 숫자 개수별 인기도 지수 + 95% 신뢰구간, 1등 자동 66%·수동 31%·반자동 3%), 최근 30회 표
  - **QR 채점**: 카메라(안드로이드 크롬 = BarcodeDetector, iOS 사파리 = jsQR 지연 로드), 사진에서 읽기, QR 링크 붙여넣기, 마킹 용지로 직접 입력(최대 5게임, 나머지 무작위). 읽는 즉시 자동 저장 + 5초 되돌리기, 같은 QR 중복 방지, 결과 시트(등수·확률·1등 세후 금액)
  - **적중 기록**(Notion 아이디어 「분석한 번호와 실제 당첨번호를 대조해 매주 적중률 기록」): 전략 4종(요즘 자주 나온·오래 쉰·역대 많이 나온·무작위 기준선)으로 매주 직전 데이터만 써서 고른 번호를 21회~최신 1,230주 채점. 다음 회차 분석 번호 + 내 기록에 담기, 최근 52주 차트, 방법별 비교, 판정(모두 무작위와 통계적으로 구별되지 않음)
  - **내 기록**: 운 지수(평균 일치 ÷ 0.8 × 100), 운 백분위(정확 합성곱 ≤500게임, 이후 정규근사), 번호 적중률·당첨 비율 vs 이론, 일치 분포 vs 이론, 등수, 행운 번호, 구매 방식별 비교, 회수율(1등 실제·4·5등 고정, 2·3등은 동행복권 확인), 회차별 복권 목록, JSON 내보내기·가져오기
  - 추첨 뒤 앱을 열면 새로 채점된 회차를 모달로 알림(`lotto-lab:seen-round`)
- 디자인: 「용지와 공」 — 분홍 잉크 마킹 용지 격자 + 컴퓨터용 펜 마킹 진하기 + 방송 추첨 공. 라이트 기본, 다크 지원(토글). 글꼴 Gothic A1 + Archivo
- 데이터: 제1회~제1,250회, 미러 3곳 전 필드 일치(PRD §9.0). 공식 엔드포인트 실호출은 Actions 첫 실행에서 확인 필요
- 테스트: 계산 로직 19개(`node --test`) + 수집·데이터 13개(`unittest`) 통과, 빌드 성공(메인 JS gzip 68KB, jsQR 47KB 지연 로드)
- 화면 확인: Playwright 390px 라이트·다크, 1280px. 가로 넘침·콘솔 오류 없음. 사진 QR → 1등 판정, 중복 방지, 잘못된 링크 오류, 직접 입력 → 추첨 대기, 되돌리기 흐름 확인
- 브랜치: 현재 원격 기본 브랜치가 작업 브랜치 `claude/jolly-euler-ekd2jv`(저장소 첫 푸시라서). `main` 없음
